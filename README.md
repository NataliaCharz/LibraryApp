# My Portable Library
## Project Description
My Library is a web application built with Java Spring Boot, allowing users to manage books and authors. The application utilizes CRUD operations for managing books and authors and integrates with an external database to fetch additional information about books by a given author.
## Technologies Used
- Java Spring Boot
- Gradle
- H2 / PostgreSQL
- Docker
- JWT
